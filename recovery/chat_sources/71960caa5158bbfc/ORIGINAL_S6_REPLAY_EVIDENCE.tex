\subsection*{Replay selection and records}
\begin{enumerate}\setlength{\itemsep}{1pt}
\item \emph{O/W/P.} Task selection, retained outputs and scan lineage are in Section~\ref{sec:rq3-design}. The archived syntax check covers O/W/P outputs only. The failing output is the OpenAgents original-issue replay (case 16633-O), which recorded zero new alerts despite failing the syntax check.
\item \emph{P1--P5.} A first screen selected 65 implementation-choice tasks from the 191 mapped positives and retained three archived patch versions per task (195 versions). Nineteen tasks were reported scanner-positive in at least one stage and seven in all three. The stages are not verified as independent model generations. These seven tasks are enriched for repeated positive outputs and are not representative. This screen led to the P1--P5 pilot, not to a documented selection rule for the separate 14-task O/W/P series. The five conditions are alternatives, not a ladder. P2--P4 are not blinded to hindsight and P5's isolation from the historical warning is not authenticated. The P1--P3 series has 21 outputs. Six tasks entered P4 and P5, with one P4 output partial and one P5 record missing; neither is counted as zero. There is no pinned baseline or head SARIF for P1--P5, and model settings are incompletely verified.
\item \emph{Earlier run and other pilots.} An earlier P1--P3 run used different definitions and produced identical patches across conditions, so it was judged invalid and scheduled for a rerun. The archive does not show whether Table~\ref{tab:p1p5} comes from that rerun. A separate Oracle A/B/C pilot is a different protocol and is not pooled.
\end{enumerate}

\suppbox{Follow-up repairs (separate from the replay comparison)}{The accompanying experimental handoff reports four additional CodeQL-guided revisions after the seven-task screening, comprising a Telegram voice-download change (2 to 0 findings), credential-path validation (6 to 0), temporary-file handling (1 to 0), and a Fleet healthcheck change (2 to 0). These before/after alert counts come from the experimental handoff after targeted intervention, not independent O/W/P or P1--P5 generations. Functional acceptance and equivalence to the requested PR features were not established; this record is not pooled with either replay table.}
