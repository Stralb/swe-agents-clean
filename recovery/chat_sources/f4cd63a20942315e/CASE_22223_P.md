Browser mode does not persist generic ChatGPT downloadable file artifacts

## Summary

When using Oracle's browser engine with ChatGPT, the assistant can return downloadable file artifacts such as source ZIPs, wheels, and sdists. Oracle recognizes these links well enough to include them in the generated markdown transcript, but it does not download/persist the actual files as session artifacts.

This seems adjacent to / a natural extension of #169, which added durable browser session artifacts (`transcript.md`, Deep Research reports, and generated-image downloads). The current artifact path appears to handle images and reports, but not generic ChatGPT downloadable files.

## Observed behavior

Oracle browser run against ChatGPT `gpt-5.5-pro` returned output like:

```markdown
Done — I created a minimal `uv`-based `llm-tool-bx` plugin project.

Files:

* [Source zip](sandbox:/mnt/data/llm-tool-bx-source.zip)
* [Wheel](sandbox:/mnt/data/llm-tool-bx/dist/llm_tool_bx-0.1.0-py3-none-any.whl)
* [sdist](sandbox:/mnt/data/llm-tool-bx/dist/llm_tool_bx-0.1.0.tar.gz)

I followed...
```

The markdown/transcript contains proper links for the generated file artifacts, so Oracle is seeing the assistant response and preserving the references. However, the linked files themselves are not downloaded into `~/.oracle/sessions/<id>/artifacts/` or surfaced as local file artifact paths in CLI output.

## Expected behavior

For ChatGPT browser sessions, Oracle should detect generic downloadable artifacts in assistant responses and persist them, similar to the existing image/report artifact handling from #169.

For example, after completion / harvest / render:

- `~/.oracle/sessions/<id>/artifacts/llm-tool-bx-source.zip`
- `~/.oracle/sessions/<id>/artifacts/llm_tool_bx-0.1.0-py3-none-any.whl`
- `~/.oracle/sessions/<id>/artifacts/llm_tool_bx-0.1.0.tar.gz`

and `oracle session <id> --render` / structured output would list them as saved artifacts.

## Environment

- Oracle CLI: `0.13.0`
- Engine: browser, driving `chatgpt.com`
- Model: ChatGPT `gpt-5.5-pro`
- Browser: Google Chrome Beta `150.0.7871.4` (Official Build) beta (arm64)
- OS: macOS arm64
