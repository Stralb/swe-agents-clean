# Research data boundaries

Raw miner SQLite databases, CodeQL databases, original third-party repository checkouts, full SARIF, prompts and agent generations are not committed automatically. Their authoritative copies remain on Wits or in researcher's separately archived, hash-verified files. The repository carries schemas, inclusion queries, small approved fixtures and manifests only.

All exports must preserve cohort membership, event chronology, target-rule identity, units of analysis and blinding separation. Publication-ready datasets require licence/privacy review, sample selection ledger and clean rerun instructions.
