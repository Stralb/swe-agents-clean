# Contributor protocol

This is a private, provenance-sensitive research repository, not a live cluster control-plane repository.

- Never push to supervisor/third-party repositories without explicit approval.
- Review generated code and data permissions before staging. Avoid secrets, absolute credential paths, private user records and bulk third-party repository snapshots.
- Import frozen raw evidence **by reference and SHA-256** before interpreting it.
- Keep scientific status labels meaningful; passing syntax and completed jobs do not establish scientific validity.
- Link new implementations to the original archive/member SHA-256 and a specific failure or methodological correction, plus tests.
- Preserve conflicting results as distinct immutable candidates until adjudication.
- All cluster commands supplied to the researcher are read-only by default. No cluster file deletions or overwrites.
